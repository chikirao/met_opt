Вариант 12. Метод множителей Лагранжа
f(x, y) = x**2 + y**2
h(x, y) = 2*x + y - 10 = 0
Область: x, y - любые действительные числа
Якобиан ограничения: [[2, 1]]
Ранг Якобиана: 1 (постоянный)
L = lam*(2*x + y - 10) + x**2 + y**2

Система Лагранжа:
  dL/dx = 2*lam + 2*x = 0
  dL/dy = lam + 2*y = 0
  dL/dlam = 2*x + y - 10 = 0

Матрица системы: [[2, 0, 2], [0, 2, 1], [2, 1, 0]]
Правая часть: [0, 0, 10]
Определитель: -10 != 0, решение единственное
Действительных кандидатов: 1

Кандидат 1:
  x = 4
  y = 2
  lam = -4
  f = 20
  невязки ограничений: [0]
  невязки стационарности: [0, 0]
  ранг Якобиана в точке: 1

Проверка на допустимой прямой:
  y = 10 - 2*x, x = t
  phi(t) = 5*t**2 - 40*t + 100
  phi'(t) = 10*t - 40
  phi''(t) = 10 > 0
  phi(t) - 20 = 5*(t - 4)**2
  минимум: x = 4, y = 2, f = 20
  предел phi(t) при t -> -oo: oo
  предел phi(t) при t -> oo: oo
  На прямой функция не ограничена сверху, максимума нет.

SymPy 1.14.0. Вычисления точные, без округлений.
