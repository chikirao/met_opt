# Лабораторная работа 3. Метод множителей Лагранжа

Поиск условного экстремума функции при ограничении-равенстве.

## Вариант 12

Номер в потоке 12. Остаток `12 mod 12 = 0`, поэтому вариант **12**.
Условие взято из третьего раздела «Свой вариант» файла `lagrange-lecture.html` с практики.

```
f(x, y) = x^2 + y^2 -> min
2x + y = 10
x, y - любые действительные числа
```

Также нужно выяснить, существует ли максимум.

## Ход решения

1. **Допустимое множество.** `h = 2x + y - 10 = 0` задаёт прямую.
   Она непуста: например, точка `(0, 10)` удовлетворяет ограничению.
   Функции гладкие, `grad h = (2, 1) != (0, 0)` всюду. Нерегулярных точек нет.
2. **Функция Лагранжа.** Беру знак плюс:
   `L = x^2 + y^2 + lam*(2x + y - 10)`. Две исходные переменные,
   одно ограничение, три неизвестных: `x`, `y`, `lam`.
3. **Полная система:**

   ```
   2x + 2lam = 0
   2y + lam = 0
   2x + y - 10 = 0
   ```

4. **Решение.** Из первых двух уравнений `x = -lam`, `y = -lam/2`.
   Подстановка в ограничение: `-2lam - lam/2 = 10`, то есть
   `-(5/2)lam = 10`. Получаю `lam = -4`, `x = 4`, `y = 2`.
   Определитель матрицы системы равен `-10`, поэтому других решений нет.
5. **Проверка.** `2*4 + 2 - 10 = 0`, `2*4 + 2*(-4) = 0`,
   `2*2 + (-4) = 0`, `f(4, 2) = 16 + 4 = 20`.
6. **Глобальность.** Параметризую всю прямую: `x = t`, `y = 10 - 2t`, `t` любое действительное.
   Тогда `phi(t) = t^2 + (10 - 2t)^2 = 5t^2 - 40t + 100 = 5(t - 4)^2 + 20`.
   Квадрат неотрицателен, равен нулю только при `t = 4`. Значит минимум глобальный и единственный.
   Дополнительно `phi'(t) = 10t - 40`, `phi''(t) = 10 > 0`.
7. **Максимум.** При `t -> +inf` и `t -> -inf` значение `phi(t) -> +inf`.
   Функция не ограничена сверху на допустимой прямой, максимума нет.

## Ответ

```
(x*, y*) = (4, 2)
lam* = -4  (при L = f + lam*h)
f_min = 20
Максимума нет.
```

Геометрически `(4, 2)` является ближайшей к началу координат точкой прямой.
Линия уровня `x^2 + y^2 = 20` касается прямой в этой точке.
Градиенты `grad f = (8, 4)` и `grad h = (2, 1)` коллинеарны:
`grad f + lam*grad h = (8, 4) - 4*(2, 1) = (0, 0)`.

## Программная проверка

Программа строит `L` из исходных выражений, сама вычисляет производные через `sympy.diff`,
решает систему через `sympy.solve` и проверяет все действительные корни подстановкой.
Печатаются множитель, значение `f`, невязки ограничения и стационарности.
Ответ в программе заранее не задан. Классификация и глобальность обоснованы выше и в отчёте.

| Проверка | Вручную | SymPy |
| --- | --- | --- |
| x | 4 | 4 |
| y | 2 | 2 |
| lam | -4 | -4 |
| f | 20 | 20 |
| h | 0 | 0 |
| невязки стационарности | (0, 0) | (0, 0) |
| число действительных решений | 1 | 1 |

## Запуск

Нужен Python 3, `sympy`, `numpy` и `matplotlib`:

```
cd L3
python -m pip install -r requirements.txt
python main.py
python make_report.py
```

`main.py` печатает расчёт и сохраняет рисунок. `make_report.py` повторно вычисляет проверку,
создаёт HTML с формулами MathML и печатает PDF через Microsoft Edge, как в первых работах.
Для формул в отчёте интернет не требуется.

| Файл | Что внутри |
| --- | --- |
| `lagrange.py` | построение L, дифференцирование, решение системы и проверка корней |
| `main.py` | данные варианта 12, вывод проверок, исследование функции на прямой, рисунок |
| `output.txt` | вывод программы |
| `img/variant12.png` | линии уровня, ограничение и функция на допустимой прямой |
| `report/Конанчук_Лаба3_Вариант12.pdf` | отчёт с ручным решением и программной проверкой |
| `report/report.html` | исходный HTML отчёта |
| `make_report.py` | сборка отчёта в HTML и PDF |
| `requirements.txt` | библиотеки для запуска |

## Вывод

Методом множителей Лагранжа найдена единственная стационарная допустимая точка `(4, 2)`.
Подстановка переменной доказала, что в ней достигается единственный глобальный минимум `20`,
а максимум отсутствует. Точные вычисления SymPy совпали с ручным решением,
все невязки равны нулю. Здесь метод применим, поскольку функции гладкие,
а градиент ограничения нигде не обращается в ноль.
