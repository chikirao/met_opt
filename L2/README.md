# Лабораторная работа 2. Метод ломаных

Поиск глобального минимума липшицевой функции на отрезке методом ломаных (методом Пиявского).

## Задача

На вход: формула функции одной переменной строкой, концы отрезка `a`, `b`, точность `eps`.
На выход: рисунок (функция, итоговая ломаная, пробы, найденная точка), приближённые `x*` и `W(x*)`,
число итераций и время счёта.

## Как работает

1. Считаем `W` в концах отрезка.
2. Между соседними посчитанными точками находим угол ломаной (пересечение двух «галочек» с наклоном ±L):
   `x = (W_лев - W_прав) / (2L) + (u_лев + u_прав) / 2`, `p = W_лев - L (x - u_лев)`.
3. Берём угол с наименьшим `p` (при ничьей левый), считаем в нём `W(x)`.
4. Зазор `delta = W(x) - p`. Если `delta < eps`, стоп.
5. Ответ: посчитанная точка с наименьшим `W`.

Константа `L` задаётся через `--L`. Если не задана, оценивается как наибольший `|ΔW / Δx|`
по соседним точкам с запасом 20%. Эта оценка нужна только для `L`, минимум перебором по сетке не ищется.

## Запуск

Нужны `numpy` и `matplotlib`.

```
cd L2
python piyavsky.py "x + sin(3.14159*x)" -1 3 0.01
python piyavsky.py "0.5*(x-2)**2 + sin(pi*x)" 0 4 1 --L 6 --show
python examples.py
```
