# Лабораторная работа 1. Задачи линейного программирования

Задача линейного программирования (ЗЛП), симплекс-метод с искусственным базисом.

## Вариант 12

Номер в списке 12, вариант 12 mod 20 = **12**.

```
Z = 2x1 + 3x2 + x3 + 4x4 → min

x1 + 2x2 + x3       ≤ 7
     x2 + x3 + x4   = 5
x1            + x4  ≥ 3

x1, x2, x3, x4 ≥ 0
```

## Ход решения

1. **Канонический вид.** В «≤» прибавляем остаток x5, из «≥» вычитаем избыток x6:

   ```
   x1 + 2x2 + x3 + x5      = 7
        x2 + x3 + x4       = 5
   x1           + x4 − x6  = 3
   ```

2. **Вспомогательная задача.** У первой строки уже есть базисная x5 (коэффициент +1).
   Во вторую и третью добавляем искусственные x7, x8:
   `Wa = x7 + x8 = 8 − x1 − x2 − x3 − 2x4 + x6 → min`.

3. **Решение вспомогательной.** Два шага: x4 ↔ x8, x2 ↔ x7. Получили Wa = 0,
   допустимая точка (0, 2, 0, 3), Z = 18.

4. **Переход к основной.** Искусственные вычеркнуты, цель выражена через свободные x1, x3, x6:
   `Z = 18 + x1 − 2x3 + x6`.

5. **Решение основной.** Два шага: x3 ↔ x2 (Z = 14), x1 ↔ x5 (Z = 23/2).
   В строке c нет отрицательных, оптимум.

Все таблицы печатает `main.py`, полный вывод в [`output.txt`](output.txt).

Правила выбора: столбец с самым отрицательным c, строка по минимуму b/a среди a > 0.
При равенстве берётся переменная с меньшим номером (правило Блэнда).
Все вычисления в `fractions.Fraction`, без округлений.

## Ответ

```
x* = (5/2, 0, 9/2, 1/2)
Z(x*) = 23/2 = 11.5
```

Проверка: 5/2 + 0 + 9/2 = 7 ≤ 7, 0 + 9/2 + 1/2 = 5, 5/2 + 1/2 = 3 ≥ 3.
В последней таблице все c > 0, поэтому оптимум единственный.
