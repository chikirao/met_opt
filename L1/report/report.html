Постановка задачи

Минимизировать $Z = 2x_{1} + 3x_{2} + x_{3} + 4x_{4}$ при условиях

$$\begin{cases} x_{1} + 2x_{2} + x_{3} \le 7 \\ x_{2} + x_{3} + x_{4} = 5 \\ x_{1} + x_{4} \ge 3 \\ x_1, x_2, x_3, x_4 \ge 0 \end{cases}$$

1. Приведение к каноническому виду

Задача уже на минимум и все правые части положительные, поэтому менять знаки не нужно. Остаётся убрать неравенства. В первое ограничение ($\le$) я добавил остаточную переменную $x_5 \ge 0$, из третьего ($\ge$) вычел избыточную переменную $x_6 \ge 0$. В целевую функцию они входят с коэффициентом 0.

$$W = 2x_{1} + 3x_{2} + x_{3} + 4x_{4} \to \min$$ $$\begin{cases} x_{1} + 2x_{2} + x_{3} + x_{5} = 7 \\ x_{2} + x_{3} + x_{4} = 5 \\ x_{1} + x_{4} - x_{6} = 3 \\ x_1, \dots, x_6 \ge 0 \end{cases}$$

2. Вспомогательная задача

Чтобы начать симплекс-метод, в каждой строке должна быть базисная переменная с коэффициентом $+1$, которой нет в других строках. В первой строке это $x_5$. Во второй такой переменной нет, а в третьей $x_6$ стоит с минусом (получилось бы $x_6 = -3 < 0$). Поэтому во вторую и третью строки я добавил искусственные переменные $x_7, x_8 \ge 0$:

$$\begin{cases} x_{1} + 2x_{2} + x_{3} + x_{5} = 7 \\ x_{2} + x_{3} + x_{4} + x_{7} = 5 \\ x_{1} + x_{4} - x_{6} + x_{8} = 3 \end{cases} \qquad W_a = x_7 + x_8 \to \min$$

Базис: $x_5, x_7, x_8$; свободные: $x_1, x_2, x_3, x_4, x_6$. Выражаю искусственные переменные через свободные и подставляю в $W_a$:

$$x_{7} = 5 - x_{2} - x_{3} - x_{4} ,\qquad x_{8} = 3 - x_{1} - x_{4} + x_{6}$$ $$W_a = 8 - x_{1} - x_{2} - x_{3} - 2x_{4} + x_{6}$$

Коэффициенты при свободных переменных идут в нижнюю строку таблицы, а в правый нижний угол $-Q = -8$.

3. Решение вспомогательной задачи

Как пересчитываю таблицу: разрешающий элемент $\hat a_{i^*j^*} = 1/a_{i^*j^*}$; разрешающая строка делится на $a_{i^*j^*}$; разрешающий столбец делится на $a_{i^*j^*}$ со сменой знака; остальные элементы по правилу прямоугольника $\hat a_{ij} = a_{ij} - \dfrac{a_{i^*j}\, a_{ij^*}}{a_{i^*j^*}}$ (так же для $b$ и строки $c$).

Вспомогательная, таблица 0

$x_{5}$$1$$2$$1$$0$$0$$7$
$x_{7}$$0$$1$$1$$1$$0$$5$
$x_{8}$$1$$0$$0$$1$$-1$$3$
$c$$-1$$-1$$-1$$-2$$1$$-8$

В строке $c$ отрицательные $c_{1} = -1, c_{2} = -1, c_{3} = -1, c_{4} = -2$. Самый отрицательный у $x_{4}$, беру этот столбец. Считаю отношения $b_i / a_{i4}$ для $a_{i4} > 0$: $x_{7}: \ 5 / 1 = 5;\quad x_{8}: \ 3 / 1 = 3$. Минимум в строке $x_{8}$. Разрешающий элемент $1$: $x_{4}$ входит в базис, $x_{8}$ выходит.

$x_{8}$ искусственная, поэтому после пересчёта её столбец вычёркиваю.

В строке $c$ отрицательные $c_{2} = -1, c_{3} = -1, c_{6} = -1$. Наименьшие значения равны, беру переменную с меньшим номером, то есть $x_{2}$. Считаю отношения $b_i / a_{i2}$ для $a_{i2} > 0$: $x_{5}: \ 7 / 2 = \frac{7}{2};\quad x_{7}: \ 2 / 1 = 2$. Минимум в строке $x_{7}$. Разрешающий элемент $1$: $x_{2}$ входит в базис, $x_{7}$ выходит.

$x_{7}$ искусственная, поэтому после пересчёта её столбец вычёркиваю.

Получилось $W_a = 0$, обе искусственные переменные вышли из базиса. Значит допустимая точка есть: $x = (0, 2, 0, 3, 3, 0)$, в нём $Z = 18$.

4. Переход к основной задаче

Ограничения беру из последней таблицы без изменений. Нижнюю строку нужно заменить на настоящую цель $Z$, но в ней есть базисные $x_2$ и $x_4$. Выражаю их из строк таблицы через свободные $x_1, x_3, x_6$:

$$x_{2} = 2 + x_{1} - x_{3} - x_{6} ,\qquad x_{4} = 3 - x_{1} + x_{6}$$ $$Z = 2x_1 + 3x_2 + x_3 + 4x_4 = 2x_1 + 3(2 + x_1 - x_3 - x_6) + x_3 + 4(3 - x_1 + x_6) = 18 + x_{1} - 2x_{3} + x_{6}$$

Отсюда новая строка $c$: коэффициенты при $x_1, x_3, x_6$, а в углу $-Q = -18$.

$c$$\frac{1}{2}$$\frac{5}{2}$$\frac{5}{2}$$-\frac{23}{2}$

Отрицательных коэффициентов в строке $c$ нет, значит дальше уменьшать цель некуда, это оптимум.

Ответ

Свободные переменные равны нулю: $x_5 = x_2 = x_6 = 0$. Значения базисных беру из столбца $b$.

$x^* = (\frac{5}{2}, 0, \frac{9}{2}, \frac{1}{2}) = (2.5, 0, 4.5, 0.5), \qquad Z(x^*) = \frac{23}{2} = 11.5$

В последней строке $c$ нет нулей, все коэффициенты больше нуля, поэтому оптимальная точка одна. Значение цели менялось так: $18 \to 14 \to \frac{23}{2}$.

Проверка

  • $1 \cdot \frac{5}{2} + 2 \cdot 0 + 1 \cdot \frac{9}{2} = 7 \le 7$
  • $1 \cdot 0 + 1 \cdot \frac{9}{2} + 1 \cdot \frac{1}{2} = 5 = 5$
  • $1 \cdot \frac{5}{2} + 1 \cdot \frac{1}{2} = 3 \ge 3$
  • все $x_j \ge 0$
  • $Z = 2 \cdot \frac{5}{2} + 3 \cdot 0 + 1 \cdot \frac{9}{2} + 4 \cdot \frac{1}{2} = \frac{23}{2}$
